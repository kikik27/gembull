## 3. Usage Guidelines

### 3.1 Primary Logo (`gembull-logo.svg`)
- Use in website headers, navigation bars, partner decks, and top of documents.
- Keep minimum clear space equal to the height of the "B" letter around the lockup.
- Never warp, distort, recolor, or change the aspect ratio.

### 3.2 Symbol / Emblem (`gembull-symbol.svg`)
- Scalable from 24px (favicon/UI badge) to large print format.
- Features: Confident geometric horns, forehead gem crown, central ritual pulse ring (`#B7FF16`), faceted muzzle, and neon jaw chevron.
- Use monochrome variants (`gembull-symbol-mono-white.svg` or `gembull-symbol-mono-lime.svg`) on photographic or patterned backgrounds where color fidelity cannot be preserved.

### 3.3 App & Token Icons (`02-icons/`)
- **Favicon**: Standard browsers use `favicon.svg` with PNG fallbacks (`16x16`, `32x32`, `48x48`).
- **NEP-141 / DEX Token Icons**: Use `gembull-token-128.png`, `gembull-token-256.png`, or `gembull-token-512.png` for NEAR wallets (Meteor, HERE, MyNearWallet), NearBlocks explorer, Ref Finance, and listing sites.

### 3.4 Disclaimers & Regulatory Rules
- Never label campaign artwork or promotional coin (`gembull-campaign-coin.png`) as deployed token metadata.
- All stock reserve visuals and metrics are **SIMULATED** secondary concepts; no real equity, shares, custody, or redemption are implied.
- GEMBULL is a community memecoin on NEAR Testnet (`gembull-core.testnet`).
