# StonkRitual Brand Asset Pack

This package contains individually separated crops from the supplied StonkRitual brand board, project-owned logo assets, UI icons, and a starter commercial/social kit.

## Quick start
1. Read `AGENTS.md` before using any asset in the product repository.
2. Read `08-guidelines/BRAND_GUIDE.md` for visual rules.
3. For Instagram setup, read `06-social/instagram/INSTAGRAM_PLAYBOOK.md`.
4. For web app use, start with `01-logos/stonkritual-primary-logo.svg`, `01-logos/stonkritual-brand-symbol.svg`, `02-mascots/` and `04-icons/`.

## Important naming and legal status
`StonkRitual` and `$RITL` remain working project name/ticker candidates. Availability and trademark clearance have not been checked. The stock reserve and receipt visuals are simulations unless a real issuer/custodian arrangement is completed.

## Folder map
- `01-logos/` — wordmark, symbol, avatar/emblem crops, OG image.
- `02-mascots/` — approved bull mascot hero and round crop.
- `03-stickers/` — six mascot reaction stickers extracted from the board.
- `04-icons/` — app icons, token icon and feature icons.
- `05-token-art/` — token/achievement badge artwork.
- `06-social/instagram/` — avatar, six feed posts, two stories and posting playbook.
- `06-social/banners/` — X/Discord banners and source social crops.
- `07-ui-elements/` — extracted visual references; rebuild controls as real UI.
- `08-guidelines/` — brand guide and palette reference.
- `09-source/` — original uploaded board for provenance.

## Provenance
Mascot and sticker crops are taken from the user-supplied brand board and preserved without changing the character identity. New project-owned symbol, wordmark lockup, feature icons and marketing templates were created for this package.
