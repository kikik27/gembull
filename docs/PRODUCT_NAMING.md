# GemBull name and token symbol

The project owner selected **GemBull** as the product name and approved the geometric bull logo for the landing page. The deployed [`gembull-core.testnet`](deployments/GEMBULL_TESTNET.md) contract reports NEP-148 token metadata **GemBull / GEMBULL**. Domain, social handle, and trademark clearance remain open; this Testnet deployment is not a mainnet launch.

The previous prototype was named **StonkRitual / RITL**. Its existing [`ritl-stonkritual.testnet`](deployments/RITL_TESTNET.md) account retains that on-chain identity. It is historical evidence, not a GemBull deployment.

The former `rNVDA` mock receipt plan was retired by the v0.2 product direction. The revised MVP uses proposed non-transferable Ritual Points and simulated stock allocation records; no stock receipt token is deployed or planned for the MVP. Neither points nor allocations represent equity, redemption, dividends, or custody.

## Before public launch

1. Check exact and similar names across web, X, GitHub, app stores, domains, and relevant trademark databases.
2. Search NEAR Testnet and Mainnet for similar token names and symbols; symbols are not globally unique.
3. Verify social handles before publishing a handle in product assets.
4. Review all stock-related language and receipt naming with the relevant legal and custody specialists before any real-money integration.
