# StonkRitual Design System Package

This directory is the source of truth for the StonkRitual web UI/UX.

| File | Purpose |
|---|---|
| `DESIGN_SYSTEM.md` | Visual language, design principles, page hierarchy, accessibility and product surfaces |
| `COMPONENT_SPEC.md` | Component variants, states, props/data needs and exact asset placement |
| `PAGE_SPEC.md` | Information architecture, routes and user journeys |
| `AGENT_ASSET_MAP.md` | Asset-to-UI mapping and app public paths |
| `CODEX_UI_INSTRUCTIONS.md` | Instructions for Codex implementation order and definition of done |
| `design-tokens.json` | Machine-readable tokens |
| `theme.css` | CSS variables and base styles to import in the application |

Read `../AGENTS.md` first, then `CODEX_UI_INSTRUCTIONS.md` before implementing any frontend UI.
